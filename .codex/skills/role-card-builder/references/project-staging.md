# Project Staging

## 目录纪律

- 默认工作目录是 `src/<项目名>/...`。
- `src` 仅允许当前正在制作的项目存在，不允许同时堆放其他无关或历史项目。
- `角色卡/` 在这里作为归档区使用，不是默认首选开发目录。

## 切换方式

- 如果 `src` 中存在不是当前制作的项目，先移到 `角色卡/` 目录归档；需要继续开发时，再从 `角色卡/` 取回 `src/`。
- 优先使用仓库已有命令 `pnpm stage:card -- <项目名>` 维护 `src` 与 `角色卡/` 的切换，不要手写搬运流程。

## 项目初建

- 开始执行前，先检查 `tavern_sync.yaml` 中是否已有该项目配置。
- 如果缺少配置，先补写正确的 `类型`、`酒馆中的名称`、`本地文件路径`，再执行 pull。
- 项目初步建设时，必须先补配置再 pull，禁止把初始模板直接复制粘贴到 `src/` 里当作项目起点。
- `pull` 在本仓库中默认指 `node tavern_sync.mjs pull <项目名>`，不是 `git pull`。
- 不要在任务完成后自动执行 push；push 由用户自行手动处理。
