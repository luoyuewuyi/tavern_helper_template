## 四类东西不要混用

### Tavern Helper JavaScript API

给 TypeScript／JavaScript 脚本和前端使用。具有函数签名、返回类型和运行环境限制，是代码实现的首选。

### Slash Command

给酒馆命令管线、快捷按钮、QR／脚本流程或某些扩展能力使用。命令可能由当前安装的扩展动态增加，不能假定每个环境都有同一清单。

### SillyTavern 宏

在提示词、角色字段、世界书或命令文本中展开字符串，例如角色名、用户、消息编号、变量和时间。宏不是通用 JavaScript API，也不保证在所有字段和阶段都展开。

### SillyTavern 内部对象

底层上下文、DOM 和内部函数。只在高层 API 没有能力且目标版本经过验证时使用；升级最容易破坏。

## 选择顺序

1. 当前项目已有封装／store／util；
2. 当前 `@types` 声明的 Tavern Helper 高层 API；
3. 当前环境实际提供的 Slash Command；
4. 目标字段中支持的宏；
5. SillyTavern 内部 API 或 DOM。

这不是绝对禁令。若任务本身是制作命令管线，Slash Command 当然是主角；若只是脚本读取消息，不要把它绕成命令字符串。

## 精确查找流程

1. 在 [`raw/api-types.txt`](raw/api-types.txt) 搜索候选函数或领域词。
2. 阅读整个声明、注释、重载、参数类型和示例，不只复制第一行。
3. 搜索当前项目的实际调用，确认它在哪个 iframe／脚本环境运行。
4. 检查是否需要等待全局初始化。
5. 确认返回是同步值、Promise、Response 还是可取消任务。
6. 确认负消息 id、`latest`、当前楼层和 swipe 的含义。
7. 用最小只读调用验证，再实现写操作。

命令行可用时示例：

```sh
rg -n "declare function generate|type GenerateConfig" references/raw/api-types.txt
rg -n "^/branch-|^/checkpoint-" references/raw/slash-commands.txt
rg -n "^### \{\{(getvar|setvar|charFirstMessage)" references/raw/sillytavern-macros.txt
```

若没有 `rg`，使用宿主的文本搜索能力。

## API 领域索引

以下名称来自本技能附带的当前类型快照；调用前仍阅读原始签名。

### 消息

- `getChatMessages`
- `setChatMessages`
- `createChatMessages`
- `deleteChatMessages`
- `rotateChatMessages`
- `retrieveDisplayedMessage`
- `formatAsDisplayedMessage`
- `refreshOneMessage`

区分持久化消息与显示 DOM。直接修改 DOM 不会自动修改聊天数据。

### 生成

- `generate`
- `generateRaw`
- `getModelList`
- `stopGenerationById`
- `stopAllGeneration`

阅读 `GenerateConfig`、`GenerateRawConfig`、prompt 顺序、自定义 API、工具调用和覆盖字段。不要凭旧示例猜 `ordered_prompts` 或 provider 参数。

### 变量与 MVU

- `getVariables`
- `replaceVariables`
- `updateVariablesWith`
- `insertOrAssignVariables`
- `getAllVariables`
- `Mvu.getMvuData`
- `Mvu.replaceMvuData`
- `Mvu.parseMessage`
- `Mvu.events.*`

写操作必须明确作用域。异步 updater 使用对应 Promise 重载。

### 世界书／Lorebook

- `getWorldbook`
- `replaceWorldbook`
- `updateWorldbookWith`
- `getWorldbookNames`
- `getLorebookEntries`
- `setLorebookEntries`

类型文件可能同时保留新旧命名。优先未废弃且与当前项目一致的 Worldbook API；迁移旧代码时先看 deprecated 注释。

### 角色、预设、人格与导入

- `getCurrentCharacterId`／`getCurrentCharacterName`
- `getCharacter`／`updateCharacterWith`
- `getPreset`／`replacePreset` 等
- `getPersona` 等
- `importRawCharacter`／`importRawWorldbook`／`importRawChat`

导入会改变外部应用状态，不因“有 API”就自动执行。

### 注入、宏样函数与脚本

- prompt 注入相关函数；
- `registerMacroLike`
- `triggerSlash`
- 脚本按钮和脚本设置函数；
- `createScriptIdIframe`
- `getScriptId`／`getIframeName`／`getCurrentMessageId`

注册宏样函数时考虑命名冲突、重载清理和输入转义。

### 初始化与事件

- `initializeGlobal`
- `waitGlobalInitialized`
- `eventOn`／`eventOnce`／`eventOff`／`eventClearAll`

不同脚本可能同时使用全局和事件。等待初始化不等于每次刷新都重新注册；清理监听也不能误删别的模块。

## Slash Command

附带的 [`raw/slash-commands.txt`](raw/slash-commands.txt) 是一次真实环境导出，包含核心命令和若干扩展命令。它比同一时点模板仓库的清单多出图像、向量、语音、翻译、摘要等扩展命令，因此：

- 把它当搜索索引，不当最低兼容保证；
- 执行前用当前环境帮助、自动补全或 `/?` 确认；
- 区分位置参数、命名参数、默认值和 pipe 返回；
- 对带 JSON、HTML、正则或用户输入的参数使用正确转义；
- 批量、删除、导入、连接 API 等命令先以只读查询确认目标；
- 扩展命令缺失时提供高层 API 或普通体验回退。

常见领域：消息与分支、checkpoint、变量、世界书、生成、注入、角色／群组、预设、正则、UI、向量库、图像、语音和扩展管理。

## 宏

附带的 [`raw/sillytavern-macros.txt`](raw/sillytavern-macros.txt) 记录当前宏名、参数和简述。使用时确认：

- 当前字段是否会进行宏替换；
- 展开是在发送模型前、显示前还是命令执行时；
- 结果是否需要 HTML／JSON／命令转义；
- 变量宏访问的是 local 还是 global；
- 条件宏的真假和缺失变量行为；
- 时间、随机和当前消息宏是否会破坏可复现性。

不要在角色设定里无意使用会每轮变化的宏，也不要把宏输出当可信 HTML。

## 错误处理

- Promise 必须处理拒绝；Response 检查状态；
- 写操作后读回关键对象或等待对应事件；
- 生成调用支持取消时，UI 同步处理取消状态；
- 无权限、未打开角色、错误 iframe 环境等预期异常给出用户可理解提示；
- API 不存在时先确认版本和运行环境，不立即添加多个猜测式 fallback；
- fallback 只保留经过验证的路径，避免一个操作被重复执行。

## 安全

- 密钥留在 SillyTavern 的连接／secret 管理中；
- 不把用户输入直接拼入 Slash 管线、选择器、HTML、正则或 JSON；
- 导入、删除、切换角色、覆盖世界书和批量消息操作属于高影响写操作；
- 外部 API 和 CDN URL 要说明数据会发送到哪里；
- 角色卡分享前检查私人端点、用户名、绝对路径和令牌。
