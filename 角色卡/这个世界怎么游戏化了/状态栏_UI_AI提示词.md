# 状态栏 UI AI 提示词

为酒馆角色卡《这个世界怎么游戏化了》制作一个可读取 MVU 变量的状态栏界面。主题是“现实被游戏系统覆盖后的技能面板”，参考用户给出的图片气质：黑色点阵背景、白色斜切信息卡、红色高亮进度条、粗黑描边、类似街机/任务终端的硬朗感。

需要展示的信息包括：玩家基础状态、当前世界/地点/时间、等级与经验、可用技能点、待分配技能经验、金钱、当前状态、技能分组、任务列表、系统日志。技能展示要突出等级、经验百分比和大类分组；任务展示要区分可接取、进行中、可提交；日志只显示最近关键事件。

功能目标：界面应从 `stat_data` 读取变量，不自行创造变量；当技能或任务为空时显示克制的空状态；移动端和桌面端都应清晰可读；信息密度偏高但不要拥挤；交互可包含“状态 / 技能 / 任务 / 日志”四个标签页。视觉应保留红白黑的系统面板冲击力，但避免完全复制示例图片。

约束：不要改 MVU 变量结构；不要把完整 HTML/CSS/JS 直接写进角色卡正文或世界书；最终应以项目内前端源码构建为 `dist/这个世界怎么游戏化了/界面/状态栏/index.html` 后再由正则加载。
