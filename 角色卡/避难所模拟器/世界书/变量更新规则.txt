---
变量更新规则:
  世界:
    type: object
    check:
      - 若发生长时间旅行、睡眠或任务，需更新日期与时间
      - 灾难本质通常不变，除非剧情揭示了新的真相
  世界.当前时间:
    check:
      - 每次回合结束根据行动消耗时间推进
      - 格式需保持24小时制 HH:MM
  世界.世界现状:
    check:
      - 随着灾难推进或季节变化（如更寒冷、辐射扩散）进行调整
  避难所.空间大小:
    type: string
    check:
      - 开局选定后通常不变，除非剧情涉及扩建或区域损坏
      - 可选值: micro(30-50人) | small(150-300人) | medium(1000-2000人) | large(10000+人) | ark(100000+人)
  避难所.空间大小具体定义:
    type: string
    check:
      - 描述避难所规模、人际关系特点、管理复杂度等
  避难所.基础生存资源.${电力|水源|食物|人口}:
    type: |-
      {
        当前负载值: number; // 或 当前人口数
        负载上限: number;
      }
    check:
      - 每日结算时根据设施消耗和人口消耗扣除
      - 探索带回资源、设施产出时增加
      - 人口不能超过负载上限，否则引发卫生或治安问题
  避难所.环境指标.设施设备:
    type: string
    check:
      - 开局选定后通常不变，除非发生重大升级或灾难性损坏
      - 可选值: normal(标准配置) | dilapidated(年久失修) | advanced(尖端科技) | unfinished(烂尾工程)
  避难所.环境指标.设施设备具体定义:
    type: string
    check:
      - 描述设施的技术水平、维护需求、故障率等特征
  避难所.环境指标.${卫生度|精神健康度}:
    check:
      - 卫生度随人口过载、尸体未处理而下降
      - 精神健康度(SAN)随灾难事件、压抑政策或物资短缺下降
  避难所.居民职业组成:
    type: string
    check:
      - 开局选定后不变，描述避难所初期的技能树偏科情况
      - 可选值: random(市井百态) | celebrities(名流聚会) | military(铁血军团) | intellectuals(象牙塔) | prisoners(重刑犯)
  避难所.居民职业组成具体定义:
    type: string
    check:
      - 描述居民的职业背景特征与对游戏玩法的影响
  避难所.居民族裔组成:
    type: string
    check:
      - 开局选定后不变，影响文化统一性与内部凝聚力
      - 可选值: diverse(国际都会) | asian(东亚后裔) | caucasian(欧美后裔) | african(非裔社群)
  避难所.居民族裔组成具体定义:
    type: string
    check:
      - 描述族裔特点、文化倾向、基因优势等
  避难所.社会制度.${分配制度|信息管控|社会伦理|治安手段|繁衍政策|对外态度|惩罚机制}:
    check:
      - 仅在玩家通过"法令卡"或做出重大决策时变更
      - 极端值的设定可能触发特定的Buff或Debuff
  避难所.宏观属性.${统治力|防御等级|隐蔽度}:
    check:
      - 统治力受资源短缺、法令执行残酷度影响
      - 防御等级随设施建造、安保人员分配提升
      - 隐蔽度随对外交往、广播发射或战斗噪音降低
  避难所.避难所试验目的:
    type: string
    check:
      - 开局选定后不变，隐藏在避难所设计中的真实实验目的
      - 可选值: normal(标准规程) | theocracy(神权降临) | chemical_control(神经化学干预) | demographics(种群样本扭曲) | behavioral(行为矫正项目) | thought_control(认知重构) | utopia(基因乌托邦)
  避难所.避难所试验目的具体定义:
    type: string
    check:
      - 描述实验的具体内容、社会影响、机制等
  派系:
    type: |-
      {
        [派系名称: string]: {
          宗旨: string;
          好感度: number; // 0-100
          领导人: string;
          人数: string; // 占比或数量描述
        }
      }
    check:
      - 玩家的决策偏向会影响不同派系的好感度
      - 好感度过低可能触发叛乱或罢工
  设施区域:
    type: |-
      {
        [设施名称: string]: {
          等级: number;
          效果: string;
          说明: string;
        }
      }
    check:
      - 建造或升级完成后添加/更新条目
      - 灾难袭击可能导致设施降级或损坏
      - 效果字段格式为多行文本，每行格式为"数值名：数值变化"或"数值名 类型：数值变化"
      - 可用数值名包括：电力/水源/食物/人口（配合"负载上限"或"当前负载值"），防御等级/隐蔽度/统治力/精神健康度
      - 示例：
        效果: |
          电力 负载上限：100
          精神健康度：25
          水源 当前负载值：-30
  仓库系统:
    type: |-
      {
        [物品名称: string]: {
          类型: '武器' | '防具' | '饰品' | '其他';
          说明: string;
          效果: {
            武力?: number;
            管理?: number;
            探索?: number;
            生命值?: number;
            防护等级?: number;
          };
          剩余数量: number;
        }
      }
    check:
      - 获得或消耗物品时更新剩余数量
      - 剩余数量为0时移除条目
      - 效果字段仅在物品具有对应属性时存在
  监督者:
    check:
      - 玩家信息，通常跟随剧情与玩家操作变动
  监督者.行动点数:
    type: number
    check:
      - 每日重置为最大值
      - 执行探索、管理、建设等消耗AP
  监督者.生命值:
    type: number
    check:
      - 受到伤害时降低
      - 归零时监督者死亡，游戏结束
  监督者.当前状态:
    type: |-
      {
        [状态名称: string]: {
          效果: string; // 描述状态效果，如"统治力-20"或"S+2"
          剩余时间: string; // 如"4周"、"3天"、"永久"
        }
      }
    check:
      - 政令改革会添加"政体动荡"状态（统治力-20，持续4周）
      - 受伤会添加"负伤"状态（降低部分数值，持续到治疗）
      - 某些事件或物品可能添加临时增益或减益状态
      - 状态可以叠加，效果累加
  监督者.S.P.E.C.I.A.L.${S|P|E|C|I|A|L}:
    type: number
    check:
      - 仅在升级、装备特殊物品或剧情重大转折时变动
      - 数值影响相关检定的成功率
  监督者.特质:
    type: |-
      { [特质名称: string]: string }
    check:
      - 开局选择或通过特殊事件习得新特质
  监督者.性格:
    type: string[]
    check:
      - 由多个性格标签组成，如：冷静、果断、谨慎、激进等
      - 通常在开局设定后不变，除非经历重大剧情转折
  外交情况:
    type: |-
      {
        [势力ID: string]: {
          势力名称: string;
          介绍: string;
          等级: number;
          好感度: number;
          当前关系: string;
        }
      }
    description:
      势力ID: "势力的唯一标识符，作为对象的 key，例如：faction_001、faction_002等。用于标识不同的势力"
      势力名称: "势力的名称，描述该势力的称呼，如：废土拾荒者联盟、新共和国、黑水公司等"
      介绍: "势力的背景介绍，描述该势力的性质、历史、目标等信息"
      等级: "势力的等级，数值类型。代表势力的实力和影响力，通常在1-10之间"
      好感度: "[-100,100]之间的整数，代表该势力对避难所的好感度。0为中立，正值为友好，负值为敌对"
      当前关系: "根据好感度描述当前与势力的关系状态，如：盟友、友好、中立、敌对、极度敌对等"
    check:
      - 开局创建：初始化为空对象 {}，势力通过外交行动逐渐发现
      - 好感度变动：完成外交行动、任务选择、互动等方式获得或失去好感度
      - 当前关系更新：根据好感度值的变化，自动更新对应的关系描述文本
      - 好感度必须在[-100,100]范围内
      - 新势力通过外交行动、探索等方式添加到外交情况中
  追随者:
    type: |-
      {
        [姓名: string]: {
          年龄: number;
          性别: string;
          外貌: string;
          性格: string;
          爱好: string;
          弱点: string;
          反差: string;
          武力: number;
          管理: number;
          探索: number;
          生命值: number;
          防护等级: number;
          状态: string; // 健康/生病/崩溃/死亡
          忠诚度: number;
          装备栏: {
             武器位: string;
             防具位: string;
             饰品工具位: string;
          };
          特质: Record<string, string>;
        }
      }
    check:
      - 🚨 极其重要：所有属性（年龄、性别、外貌、性格、爱好、弱点、反差、武力、管理、探索、特质等）都必须在角色创建时完整设定，绝对不可留空或后补！
      - 🚨 创建新追随者时，必须一次性提供所有必需属性的完整信息，包括但不限于：
        * 年龄（具体数值）
        * 性别（男/女/其他）
        * 外貌（详细的外貌描述）
        * 性格（性格特征描述）
        * 爱好（兴趣爱好）
        * 弱点（角色的弱点）
        * 反差（性格的反差面）
        * 武力/管理/探索（具体数值）
        * 特质（至少一个特质，格式为 { 特质名: 效果描述 }）
      - 外貌/性格/爱好/弱点/反差通常在角色创建时设定，除非剧情重大转折
      - 战斗受伤扣减生命值，归零标记为死亡
      - 长期物资短缺或受到惊吓影响状态(精神崩溃)和忠诚度
      - 装备变更时更新装备栏
